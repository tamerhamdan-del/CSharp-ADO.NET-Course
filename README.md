# C# & Database Connectivity (ADO.NET)

This repository contains my projects and exercises from **Course 18 - C# & Database Connectivity (ADO.NET)**.

## 📚 What I Learned

During this course, I learned how to work with databases in C# using **ADO.NET**, including:

* Connecting C# applications to SQL Server databases.
* Using `SqlConnection` to connect to the database.
* Using `SqlCommand` to execute SQL queries and commands.
* Using `SqlDataReader` to read data from databases.
* Working with `DataTable` and `DataView`.
* Retrieving, inserting, updating, and deleting data.
* Working with parameters in SQL queries.
* Handling database operations from C# applications.
* Understanding basic Database Connectivity concepts.

## 🛠️ Technologies Used

* C#
* .NET
* ADO.NET
* SQL Server
* Visual Studio

## 📂 Projects

This repository contains the different projects and exercises I completed while studying ADO.NET and database connectivity.

Each project focuses on practicing different concepts related to connecting C# applications with databases and working with data.

## 🎯 Course Goal

The goal of this course was to understand how C# applications communicate with databases and how to retrieve and manipulate data using **ADO.NET**.
